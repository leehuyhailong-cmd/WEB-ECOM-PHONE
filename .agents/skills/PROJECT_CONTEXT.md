1. Tên đề tài: Hệ thống quản lý và bán hàng trực tuyến cho cửa hàng điện thoại Phonestore
2. Lĩnh vực đề tài:Phần mềm doanh nghiệp
3. Mục Tiêu:
    3.1 : " - Hiểu và áp dụng quy trình xây dựng hệ thống phần mềm quản lý bán hàng trực tuyến, bao gồm các bước: khảo sát, phân tích yêu cầu, thiết kế, cài đặt và kiểm thử;
          - Kỹ năng phân tích, thiết kế cơ sở dữ liệu và xử lý dữ liệu cho hệ thống bán điện thoại (sản phẩm, khách hàng, đơn hàng, thanh toán);
          - Phát triển ứng dụng web theo mô hình fullstack: xây dựng giao diện (frontend), xử lý logic (backend) và quản lý dữ liệu (database);
          - Tích lũy kinh nghiệm triển khai thực tế một hệ thống thương mại điện tử: giỏ hàng, tìm kiếm sản phẩm, đặt hàng, thanh toán, quản lý người dùng.
    3.2 : Công nghệ sử dụng :"- JavaScript: Ngôn ngữ lập trình chính, sử dụng cho cả phía frontend (giao diện) và backend (xử lý logic, kết nối dữ liệu);
          - MongoDB: Hệ quản trị cơ sở dữ liệu NoSQL dùng để lưu trữ thông tin sản phẩm, khách hàng, đơn hàng và các dữ liệu khác của hệ thống;
          - HTML, CSS: Ngôn ngữ xây dựng giao diện web (frontend), tạo bố cục, hiển thị và xử lý tương tác với người dùng;
          - Node.js: Môi trường phát triển phía server, cho phép xây dựng backend xử lý logic, giao tiếp với cơ sở dữ liệu và cung cấp API cho hệ thống."
    3.3 : Kỹ năng phát triển :"- Giao tiếp, phân tích yêu cầu và trao đổi với khách hàng/người dùng để xác định nhu cầu thực tế;
          - Kỹ năng tìm kiếm và tổng hợp thông tin để xây dựng các chức năng phù hợp cho hệ thống bán điện thoại;
          - Kỹ năng triển khai các tính năng web thương mại điện tử: tìm kiếm sản phẩm, lọc theo giá, quản lý giỏ hàng, thanh toán trực tuyến, chatbot tư vấn khách hàng;
          - Kỹ năng phân tích dữ liệu để đưa ra báo cáo và thống kê (ví dụ: top sản phẩm bán chạy trong tháng);
          - Tính độc lập, chủ động, kiên trì và sáng tạo trong công việc."
